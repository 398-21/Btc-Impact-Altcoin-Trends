# 🪙 Bitcoin Impact on Altcoin Trends

This repository explores how Bitcoin's price movements and associated news impact other cryptocurrencies in the broader crypto ecosystem. Leveraging Python-based data science and NLP techniques, we examine whether Bitcoin's trends can influence or predict altcoin behavior.

## 📘 Background

Bitcoin was the first cryptocurrency to use a decentralized ledger system (blockchain) and proof-of-work consensus. Since its inception, thousands of altcoins have emerged, creating a dynamic and volatile market. While research has focused on Bitcoin and search trends, this project investigates **how Bitcoin news and price affect other cryptocurrencies**.

## 🎯 Project Objectives

- Analyze news sentiment surrounding Bitcoin
- Study how Bitcoin's rise/fall correlates with changes in altcoin prices
- Use Natural Language Processing (NLP) to understand sentiment patterns
- Visualize relationships among selected coins over time

## 📊 Features

- Sentiment extraction from Bitcoin-related headlines
- Correlation analysis between BTC and popular altcoins (e.g., ETH, XRP, LTC)
- Visualization of price movement and sentiment impact
- Basic statistical/regression modeling

## 🧪 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/btc-impact-altcoin-trends.git
   cd btc-impact-altcoin-trends
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open the Jupyter notebook:
   ```bash
   jupyter notebook Btc-Impact-Altcoin-Trends.ipynb
   ```
